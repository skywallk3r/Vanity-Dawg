How do I know this is safe?

• Key generation runs entirely on your device — the grinding code is open for anyone to inspect, and the same code ships as a downloadable offline file you can run in Airplane Mode.
• The app never receives, transmits, or stores private keys. Payments (for the optional unlock) go wallet-to-wallet on Base; keys are not part of that, ever.
• Don't trust — verify: watch your network traffic while it grinds. The only requests are this page itself and, if you tap Unlock or Cast, the Farcaster actions you asked for.
