# Vanity Dawg — Farcaster Mini App

The vanity wallet generator as a Farcaster mini app. Same on-device
grinding as the offline file (the crypto core is byte-identical), wrapped
with the Farcaster SDK: in-app launch, share-your-find casts, and a
one-time USDC unlock for longer patterns.

**Privacy model (unchanged):** keys are generated in the user's browser
and never transmitted. The Farcaster layer only ever touches the PUBLIC
address (for the share cast) and the unlock payment (wallet → payout
address on Base, via the host wallet's own confirmation screen).

## How it makes money

- **Free:** patterns up to 3 characters, both chains, forever.
- **Unlock (one-time, per device):** longer patterns (Solana ≤ 6 chars,
  Ethereum ≤ 8). Default price **2 USDC on Base**, paid with the SDK's
  `sendToken` action straight to `payoutAddress` in `src/config.js`.
- The unlock flag is a `localStorage` flag — deliberately simple for v1.
  It is a paywall of politeness, not DRM: anyone technical can flip it.
  That's acceptable at a $2 price point; a server-verified unlock (paid
  FID recorded by a backend after confirming the tx) is the v2 upgrade
  if the app earns enough to justify a backend.

## Project layout

- `public/` — **the deployable static site.** No build step needed to
  host it as-is (the SDK bundle `app.js` is prebuilt and committed).
  - `index.html` — page + `fc:miniapp` / `fc:frame` embed meta tags
  - `core.js` — the verified crypto core (same code as the offline file)
  - `app-ui.js` — generator UI + freemium logic
  - `app.js` — bundled Farcaster SDK integration (esbuild output)
  - `.well-known/farcaster.json` — the manifest (placeholders — see below)
  - `assets/` — icon (1024×1024), splash (200×200), embed image (3:2).
    Placeholder art: a gold circle. Replace with real art before launch.
- `src/config.js` — **the file you edit:** domain, payout address, price.
- `src/miniapp.js`, `src/entry.js` — SDK integration source.
- `scripts/sync-domain.mjs` — rewrites the domain placeholder everywhere.

## Run it locally

```bash
npm install
npm run dev        # builds app.js and serves public/ on :8023
```

Open http://localhost:8023 — standalone mode (no Farcaster features,
everything else works). The dev server here was verified end-to-end:
free grind, paywall, and simulated-unlock flows all pass in a DOM test.

## Luke's launch steps (the parts only you can do)

1. **Get a Farcaster account** — install Warpcast, sign up (small fee).
   The account owns the app; its signature is what the manifest carries.
2. **Host `public/`** — any static host. Easiest with your GitHub:
   push this project, import it in Vercel (or Cloudflare Pages), set the
   publish/output directory to `public`. A custom domain is best (the
   manifest signature binds to the exact domain); a `*.vercel.app`
   subdomain also works.
3. **Set your config** in `src/config.js`: your domain, your payout
   address (an EVM address you control — payments arrive as Base USDC),
   and the price if you want something other than 2 USDC.
4. **Stamp the domain in:** `npm run sync-domain -- your.domain.com`
   then `npm run build` (config is baked into `app.js`), then redeploy.
5. **Sign the manifest** — in the Farcaster developer tools
   (farcaster.xyz → Developers → Mini Apps → Manifest tool), enter your
   domain and sign with your account. Paste the resulting
   `accountAssociation` object into `public/.well-known/farcaster.json`,
   replacing the three `REPLACE_WITH_...` values. Redeploy.
6. **Verify:** open `https://your.domain.com/.well-known/farcaster.json`
   in a browser — it must load as JSON with your real signature. Then
   open the app inside Warpcast once to confirm it launches past the
   splash screen.
7. **Launch:** cast the app URL from your account. The embed card renders
   with the "Grind my vanity wallet" button; every user's "Cast my find"
   is free distribution.

## Notes / known limits

- The manifest `accountAssociation` cannot be generated by Muse — it
  must be signed by your Farcaster account key. Same for the Warpcast
  account itself and the hosting account login.
- `sendToken` host support: verified against `@farcaster/miniapp-sdk`
  0.4.0's own type definitions (the version bundled here). Some
  third-party Farcaster clients support fewer actions than Warpcast; the
  unlock button explains itself when the host can't pay.
- Changing price or payout address later: edit `src/config.js`,
  `npm run build`, redeploy. Changing the domain means re-signing the
  manifest (step 5) for the new domain.
- Optional v2: real icon/splash art, 3 app screenshots (1284×2778) for
  the directory listing, server-verified unlocks, notifications via
  `webhookUrl` (needs a backend endpoint).
